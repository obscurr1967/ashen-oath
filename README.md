# ashen-oath
Выбери героя и пройди 4 уровня, побеждая врагов. У тебя 3 сердца. Собирай монеты и открывай сундуки для лечения. Победи всех врагов, чтобы открыть портал.  ПК: A/D — движение, Пробел — двойной прыжок, J — атака, K — способность или превращение друида в медведя. На телефоне используй экранные кнопки.
